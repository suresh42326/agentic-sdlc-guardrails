# TicketDesk (worked example)

This folder shows how the template looks after you apply it to a small product. It is not an application. There is no server, database, or frontend to run.

In the story these documents tell, TicketDesk is a support-ticket web app. Staff create and assign tickets. A model suggests a category, a priority, and a reply. A human reviews the reply before it is sent.

| Document | What it shows |
|---|---|
| [AGENTS.md](AGENTS.md) | Project instructions an agent reads |
| [docs/constitution.md](docs/constitution.md) | A filled constitution |
| [docs/security/threat-model.md](docs/security/threat-model.md) | An illustrative threat model |

The numbers and threats are teaching material for a fictional product. They are not a completed assessment of a real system.

Copy what you need into the root of your own repository. Delete this folder when you no longer want the sample.
